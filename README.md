# 自我介绍体检 · self-intro-checkup

> 看看你的自我介绍，面试官听进去了多少。

一个给面试自我介绍做结构体检的 skill，也能用在**跟老板提加薪、要资源**这类要说服对方的场合。

它依据金字塔原理和麦肯锡电梯法则，做四件事：

1. **逐句标注**：每句话是在说结论、理由、证据，还是铺垫、表功、正确的废话
2. **搭出你这段话本该有的金字塔**：结论是什么，2 到 3 条理由，证据挂在哪
3. **站到对方的位置上**：面试官听到第几句时，心里在想什么
4. **给一版改好的**：事实一个字不改、不新增，只是重新排好，能直接念出口

它只用你写进去的内容，不替你编经历和数字。所以你写得越具体，它给你的结果越有用。结果出来，你自己再核对一遍。

## 怎么装

不会写代码也能装。在 WorkBuddy、Codex、Claude 这类能装 skill 的 AI 工具里，直接说：

```
帮我安装这个 skill：https://github.com/LindaD0710/self-intro-checkup
```

装好以后这样用：

```
用自我介绍体检帮我看看这段自我介绍：（贴上你的自我介绍）
```

## 没有能装 skill 的工具？

用 [提示词版](提示词版.md)：整段复制，粘进豆包、DeepSeek、Kimi 都能用。
